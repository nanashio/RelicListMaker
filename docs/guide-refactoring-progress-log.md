# リファクタリング進行チェックリスト

RelicListMaker のリファクタリングを進める際に、どのステップに取り組んでいるかと必要なフォローアップを記録するためのメモです。実際の手順や検証項目は [docs/guide-refactoring-playbook.md](./guide-refactoring-playbook.md) に統合したので、ここでは参照リンクと進捗ログのテンプレートをまとめます。

## 参照ガイド
- ステップごとの必須テストは「[ステップ別チェックリスト](./guide-refactoring-playbook.md#5-%E3%82%B9%E3%83%86%E3%83%83%E3%83%97%E5%88%A5%E3%83%81%E3%82%A7%E3%83%83%E3%82%AF%E3%83%AA%E3%82%B9%E3%83%88)」。
- 推奨テストの洗い出しは「[追加テストのアイデア](./guide-refactoring-playbook.md#6-%E8%BF%BD%E5%8A%A0%E3%83%86%E3%82%B9%E3%83%88%E3%81%AE%E3%82%A2%E3%82%A4%E3%83%87%E3%82%A2)」。
- 課題管理のテンプレートは「[ペンディング事項テンプレート](./guide-refactoring-playbook.md#7-%E3%83%9A%E3%83%B3%E3%83%87%E3%82%A3%E3%83%B3%E3%82%B0%E4%BA%8B%E9%A0%85%E3%83%86%E3%83%B3%E3%83%97%E3%83%AC%E3%83%BC%E3%83%88)」。
- 動作確認の流れやコマンド例は、同ガイドのセクション 8〜10 を参照。

## 進行ステータス記録
以下のテーブルをコピーして、どのステップをいつ完了したか、実行した検証コマンド、気づきやフォロータスクを記録してください。`ステータス` には `未着手` / `進行中` / `完了` など任意の区分を利用できます。実際の記録は別ドキュメント（例: 各リファクタリング計画書や進捗メモ）に残し、本ファイルはテンプレートおよび手順の参照に限定してください。

| ステップ | 日付 | ステータス | 実行した検証コマンド | 所感・フォロータスク |
| --- | --- | --- | --- | --- |
| ステップ0 | YYYY-MM-DD |  |  |  |
| ステップ1 | YYYY-MM-DD |  |  |  |
| ステップ2 | YYYY-MM-DD |  |  |  |
| ステップ3 | YYYY-MM-DD |  |  |  |
| ステップ4 | YYYY-MM-DD |  |  |  |

必要に応じてテーブルを拡張し、追加ステップや反復確認の履歴を残してください。

## ペンディング事項の扱い
未解決の課題はガイド内のテンプレートを用いて整理し、本ファイルからは該当セクションへのリンクを貼るか、Issue 番号などのメタ情報だけ記載すると追跡しやすくなります。

## メモ欄
自由記述で決定事項や注意点、レビュアーへの共有事項を追記してください。長文になる場合は別ドキュメントに切り出し、本ファイルにはリンクだけ残す運用を推奨します。
