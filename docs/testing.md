# テスト実行ガイド

本プロジェクトでは Python 部分の自動テストとして `pytest` を採用しています。開発時・レビュー時の確認は次のコマンドを実行してください。

```bash
pytest
```

フロントエンド (JavaScript/CSS) については、現在のところ自動テスト環境を提供していません。挙動確認が必要な場合は、`viewer_server.py` などを用いたローカル起動で手動確認してください。将来的にニーズがあれば、`npm` ベースのテストセットアップを追加する予定です。

他に必須のテストコマンドはありません。`pytest` が成功すれば Python 側のテスト観点は満たされます。
