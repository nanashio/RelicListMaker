# 計画書ペンディング課題まとめ

## gallery.js リファクタリング計画
- `templates/gallery/storage/manager.js` の OPFS 連携と CSV 保存ルートの長期運用を検証するサンプルデータが不足している。追加データを収集し、互換性確認の結果を記録する。
- Playwright フィクスチャのセットアップコスト削減策（ブラウザバイナリの事前キャッシュ等）を検討し、実施時は `docs/guide-testing.md` に反映する。

## GUI アプリ リファクタリング計画
- Tkinter ベース GUI を自動検証できるテスト手法（例: pytest-tkinter 等）の適用可否を調査し、GUI 全体テストの穴を埋める。
- Windows 固有のコンソール接続 (`_windows_cli_output`) をサービス層へ切り出す際の互換性を検証し、差分があればドキュメント化する。

## viewer_server リファクタリング計画
- 保存 API を CSV 以外の形式（JSON / SQLite 等）へ拡張する要件の有無を関係者に確認し、必要なら設計案を作成する。
- インデックスページをテンプレート化したことで発生した国際化やカスタムデザイン対応の範囲を決定し、翻訳・テーマ差し替え方針を整理する。

## Template Gallery CSS リファクタリング計画
- CSS Modules や PostCSS など追加ツールの導入要否を再評価し、採用する場合はビルド手順と影響範囲を追記する。
